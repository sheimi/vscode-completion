# Changelog

## 0.1.0

- Initial VS Code inline-completion provider.
- OpenAI Chat Completions and Responses API support.
- Anthropic Messages API support for Claude.
- Configurable model, API base URL, Chat token dialect, and secure origin-bound credentials.
- Cancellation, debounce, timeout, response sanitization, and bounded context.
- Responses API storage opt-out and response-size limits.
- Canonical list-form Responses API input for strict compatible endpoints.
